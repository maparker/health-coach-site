Privacy Policy

Effective date: June 8, 2026

Overview

Health Coach is a personal, self-hosted web application built for private use by its owner. It is not a commercial product and has no public user base. This policy describes how data accessed through Google Health is handled.

Data accessed

Health Coach connects to Google Health to read the following data types from the owner's Fitbit device:

  • Steps and daily activity
  • Sleep sessions and sleep stages
  • Heart rate measurements
  • Resting heart rate
  • Heart rate variability (HRV)
  • Body weight
  • Blood oxygen saturation (SpO₂)
  • Exercise sessions and heart rate zones

This data is accessed via the Google Health API using OAuth 2.0, with read-only permission scopes. The application does not write any data back to Google Health.

How data is stored

All data is stored locally in a SQLite database on the owner's private server. No data is transmitted to, stored on, or processed by any third-party service, with the following exception:

A compact summary of recent health metrics (sleep hours, resting heart rate, steps, and recent workout ratings) is sent to the Anthropic API to generate a daily coaching briefing and adaptive workout plan. This summary contains no personally identifying information beyond fitness metrics. Anthropic's data handling is governed by their privacy policy.

Data sharing

Health data is never sold, rented, shared with, or disclosed to any third party, advertiser, analytics service, or other entity. The application has no analytics, no tracking pixels, and no external scripts beyond Google Fonts.

Data retention

Health data is cached locally for up to 5 minutes to reduce API calls. Historical data (weight logs, workout check-ins, chat history) is retained indefinitely on the owner's server and can be deleted at any time by the owner directly through the database.

Access

The application is accessible only to its owner via password-protected session authentication. There is no public registration or multi-user access.
